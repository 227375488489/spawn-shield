# Changelog

## 2.0.1

- Исполняемый бит `gradlew` для GitHub Actions.
- Версия в `plugin.yml` обновляется корректно, сборка выпуска проходит в CI.

## 2.0.0

- Полностью самостоятельный плагин `SpawnShield`, без AuraCore и namespace `aura.*`.
- Кинематографичный `/spawn`: затемнение, заголовок, action bar, звуки, частицы.
- Сохранение точной точки спавна с yaw/pitch, выравнивание по центру блока.
- Отмена телепорта при движении и уроне с сообщениями.
- Спасение из бездны по высоте мира и VOID-урону.
- Полная защита мира спавна: блоки, сущности, взрывы, жидкости, огонь, погода, голод, мобы, урон.
- Команды `/spawn set|reload|edit`, права `spawnshield.*`.
- Исправлен старый конфиг `worlds:spawn` → `spawn`.
